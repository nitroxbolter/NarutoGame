# Sistema de Jutsus

## Objetivo

O sistema de jutsus precisa ser o centro do combate e da identidade do personagem. Ele deve crescer junto com o jogador, recompensando uso, domínio e escolhas de build.

## Estrutura de uma técnica

- Nome.
- Elemento ou tipo.
- Requisito.
- Custo de chakra.
- Tempo de recarga.
- Efeito principal.
- Possível evolução.
- Experiência individual.
- Nível máximo de domínio.

## Experiência individual do jutsu

Cada jutsu possui sua própria proficiência.

### Nível de domínio

- Nível 1: aprendizado bruto.
- Nível 2: execução estável.
- Nível 3: uso confiável.
- Nível 4: uso refinado.
- Nível 5: domínio máximo.

### Ganho de experiência

O jutsu ganha experiência quando é usado em combate, treino ou missão.

XP ganho por uso = base do jutsu x dificuldade da ação x bônus de contexto

### Exemplos de contexto

- Acerto em combate real: XP normal.
- Uso em treino ou alvo fraco: XP reduzido.
- Uso em missão difícil ou contra alvo superior: XP aumentado.

## Dificuldade por rank

O rank do jutsu deve influenciar custo, aprendizado e ganho de experiência.

| Rank do jutsu | Perfil | Impacto |
| --- | --- | --- |
| Básico | Fácil de aprender | Mais XP por repetição, menor custo |
| Intermediário | Requer domínio real | XP equilibrado e custo médio |
| Avançado | Exige build consistente | Menos XP por uso simples, maior recompensa em desafio |
| Supremo | Conteúdo raro | Exige condições especiais e treino pesado |

## Nível máximo

- O nível máximo sugerido para cada jutsu é 5.
- Depois do nível máximo, o jutsu pode desbloquear variações, não mais níveis.

## Dependências

### Dependência de elemento

- Jutsus elementais exigem o elemento correto.
- Jutsus de combinação exigem todos os elementos envolvidos.

### Dependência de especialização

- Ninjutsu favorece jutsus elementais e de chakra puro.
- Taijutsu favorece técnicas físicas, burst e mobilidade.
- Genjutsu favorece controle, ilusões e manipulação.
- Fuinjutsu favorece selamento, barreiras e controle de área.

### Dependência de rank ninja

| Rank do personagem | Acesso sugerido |
| --- | --- |
| Academia | Técnicas básicas e utilitárias |
| Genin | Jutsus simples e primeiro kit real |
| Chunin | Jutsus intermediários e variações elementais |
| Jonin | Jutsus avançados e técnicas de assinatura |
| ANBU / Sannin / Kage | Técnicas raras, secretas ou de elite |

## Limite de jutsus equipados

Os slots servem para forçar decisão de build.

| Rank | Slots sugeridos |
| --- | --- |
| Academia | 2 |
| Genin | 4 |
| Chunin | 6 |
| Tokubetsu Jonin | 7 |
| Jonin | 8 |
| ANBU | 8 |
| Sannin | 9 |
| Kage / Hokage | 10 |

## Direção de design

- Jutsus simples no começo.
- Técnicas mais complexas à medida que o jogador progride.
- Cada jutsu precisa ter função clara.
- O sistema deve premiar uso inteligente, não spam.
