# Kekkei Genkai

## Função

Kekkei Genkai são vantagens raras que ampliam a identidade de um personagem ou clã.

## Direção do sistema

- Devem ser raras e significativas.
- Precisam ter requisitos claros.
- Não devem substituir a progressão normal.

## Componentes sugeridos

- Combinações elementais.
- Linhagens especiais.
- Técnicas exclusivas.
- Regras de desbloqueio e limite.
