# Ranks Ninja

## Estrutura

Os ranks representam status, responsabilidade e acesso a conteúdo.

## Escada sugerida

- Academia.
- Genin.
- Chunin.
- Tokubetsu Jonin.
- Jonin.
- ANBU.
- Sannin.
- Kage.

## Direção de design

- Cada rank deve abrir conteúdo real.
- Promoções precisam ter valor social e mecânico.
- O sistema deve dar sensação de carreira, não só de level.
