# Sistema PvP

## Objetivo

O PvP precisa funcionar como expressão de build, posicionamento e domínio de jutsus, não só como disputa de números.

## Modos possíveis

- Arena.
- Duelo.
- Torneio.
- Guerra entre grupos.

## Direção de balanceamento

- O PvP deve ser legível.
- Recompensas precisam existir, mas sem incentivar abuso.
- O sistema precisa conviver com PvE e progressão.
