# DECISOES PENDENTES

Este arquivo lista apenas o que ainda falta fechar. Tudo que já foi definido fica nos documentos específicos do projeto.

## Como usar

Cada item abaixo deve ser acompanhado de:

- Pergunta.
- Contexto.
- Opções.
- Impacto no design.
- Decisão escolhida quando houver consenso.

## Pendências atuais

### Quantas profissões um personagem pode possuir?

- Contexto: afeta liberdade de build, economia e especialização.
- Opções: 1, 2 ou profissão primária + secundária.
- Status: pendente.

### Haverá troca de profissão?

- Contexto: evita travamento de build e impacta valor de escolha inicial.
- Opções: nunca, com custo alto, por missão ou por item raro.
- Status: pendente.

### Quais vantagens o Hokage terá além do título?

- Contexto: precisa dar valor ao cargo sem virar abuso administrativo.
- Opções: vantagens sociais, bônus de vila, acesso a área privada, ordens especiais.
- Status: pendente.
