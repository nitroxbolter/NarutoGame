# Skills

## Função

Skills são as habilidades e técnicas que o personagem domina ao longo da jornada. Elas organizam o que o ninja consegue fazer em combate, suporte e utilidade.

## Estrutura sugerida

- Ninjutsu.
- Taijutsu.
- Genjutsu.
- Mobilidade.
- Defesa.
- Utilidade.
- Técnicas de elemento.

## Domínio de skill

Cada skill pode ter estágios de domínio:

1. Aprendida.
2. Treinada.
3. Aperfeiçoada.
4. Mestre.

## O que pode evoluir

- Dano.
- Custo de chakra.
- Tempo de recarga.
- Alcance.
- Precisão.
- Efeitos secundários.

## Direção de design

- Skills precisam ser aprendidas com intenção.
- O uso repetido deve gerar domínio e identidade.
- O sistema deve permitir builds físicas, técnicas e híbridas.
