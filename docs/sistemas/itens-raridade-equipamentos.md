# Itens, Equipamentos e Raridade

## Categorias de Itens

| Categoria | Exemplos |
| --- | --- |
| Armas ninja | Kunai, shuriken, senbon, fuuma shuriken |
| Ferramentas | Bombas de fumaça, armadilhas, fios, talismãs |
| Roupas | Trajes ninja, mantos, coletes, faixas |
| Proteções | Armaduras leves, luvas, botas, bandanas |
| Consumíveis | Cura, chakra, antídotos, comida |
| Pergaminhos | Jutsus, invocações, mapas, receitas |
| Materiais | Minérios, madeira, ervas, peixes, tecidos |
| Relíquias | Itens raros de bosses, bijuus e eventos |

## Raridades

| Raridade | Cor sugerida | Uso |
| --- | --- | --- |
| Comum | Cinza | Itens básicos e recursos simples |
| Incomum | Verde | Equipamentos melhores e materiais úteis |
| Raro | Azul | Drops de dungeons e crafting avançado |
| Épico | Roxo | Bosses, eventos e receitas difíceis |
| Lendário | Dourado | Conteúdo endgame e itens únicos |
| Mítico | Vermelho | Bijuus, Otsutsuki ou eventos raríssimos |

## Atributos em Equipamentos

- Ataque físico.
- Defesa.
- Chakra máximo.
- Vida máxima.
- Treino.
- Mentalidade.
- Controle de chakra.
- Resistência elemental.
- Velocidade.
- Redução de cooldown.
- Bônus de profissão.

## Filosofia de Itemização

O poder principal vem do personagem. Itens devem:

- Especializar a build.
- Abrir opções de estilo.
- Recompensar exploração.
- Alimentar crafting e economia.
- Criar objetivos de médio e longo prazo.
