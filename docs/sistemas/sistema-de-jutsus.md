# Sistema de Jutsus

## Objetivo

O sistema de jutsus precisa ser o centro do combate e da identidade do personagem.

## Estrutura de uma técnica

- Nome.
- Elemento ou tipo.
- Requisito.
- Custo de chakra.
- Tempo de recarga.
- Efeito principal.
- Possível evolução.

## Direção de design

- Jutsus simples no começo.
- Técnicas mais complexas à medida que o jogador progride.
- Cada jutsu precisa ter função clara.
