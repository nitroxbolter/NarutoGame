# Naruto Shinobi RPG

Projeto de servidor MMORPG inspirado em uma jornada shinobi original para TFS 1.4.2 + OTCv8.

A proposta e simples: o jogador cria um ninja proprio, evolui por merito, constrói reputação em uma aldeia viva e progride por meio de treino, missões, jutsus, economia e rank.
