# Catálogo de Jutsus

## Objetivo

O catálogo organiza as técnicas do jogo para facilitar leitura, balanceamento e expansão.

## Organização sugerida

- Por elemento.
- Por rank.
- Por tipo de dano ou suporte.
- Por especialização.

## Direção de manutenção

- O catálogo deve ser fácil de atualizar.
- Técnicas antigas precisam continuar legíveis.
- Novos jutsus devem seguir o padrão do sistema.
