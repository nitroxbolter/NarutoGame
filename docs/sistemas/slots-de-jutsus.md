# Slots de Jutsus

## Função

Os slots limitam quais jutsus o jogador leva para combate, forçando escolhas e identidade de build.

## Direção de design

- Poucos slots no começo.
- Expansão gradual por rank, treino ou progresso.
- Incentivo a montar kits diferentes para situações diferentes.

## Objetivo de balanceamento

O sistema deve impedir que o jogador tenha acesso livre a tudo ao mesmo tempo, sem deixar a customização pesada demais.
