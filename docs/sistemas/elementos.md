# Elementos

## Visão geral

Os elementos definem a identidade ofensiva e defensiva do personagem. Eles devem ser fáceis de entender no começo e profundos o bastante para permitir especialização depois.

## Elementos base

- Katon.
- Suiton.
- Fuuton.
- Raiton.
- Doton.

## Direção de progressão

- O primeiro elemento deve ser acessível.
- Expansões e combinações devem surgir com treino e rank.
- Cada elemento precisa ter função clara em combate e em progressão.
