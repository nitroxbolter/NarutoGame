# Criação de Personagem

## Objetivo

A criação de personagem define a entrada do jogador no mundo e precisa reforçar a fantasia de ser um ninja proprio, não um heroi pronto.

## Elementos principais

- Nome e aparência.
- Vila inicial.
- Histórico curto.
- Primeiras escolhas de identidade.
- Elemento inicial ou afinidade inicial, se houver.

## Direção de design

- O jogador deve entender suas opções sem excesso de complexidade.
- A criação precisa preparar a progressão futura, não travá-la.
- As escolhas iniciais devem ter impacto, mas não criar arrependimento extremo.
