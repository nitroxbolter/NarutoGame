# Naruto Shinobi RPG

</div>

Projeto de servidor MMORPG inspirado em uma jornada shinobi original para TFS 1.4.2 + OTCv8.

A proposta é simples: o jogador cria um ninja próprio, evolui por mérito, constrói reputação em um mundo vivo e progride por meio de treino, missões, jutsus, elementos, equipamentos, PvP e cooperação.
