# Princípios do Projeto

## Papel

Este documento define as regras que guiam todas as mecânicas do projeto.

## Princípios centrais

- Identidade própria antes de fanservice.
- Progressão antes de excesso de conteúdo.
- Jutsus como conquista.
- Economia útil em todas as fases.
- Mundo vivo com aldeias, NPCs e eventos.
- Expansão gradual, sem perder clareza.

## Uso prático

Quando surgir uma nova mecânica, ela deve ser testada contra estes princípios antes de entrar no MVP.
