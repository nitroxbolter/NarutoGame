# Balanceamento

## Papel no projeto

Balanceamento é o trabalho de manter progresso, combate e economia coerentes entre si.

## Áreas que precisam de cuidado

- Dano de jutsus.
- Custo de chakra.
- Escala de atributos.
- Economia e inflação.
- Recompensas por atividade.

## Direção de design

- Ajustes devem partir de dados e teste prático.
- Cada sistema novo precisa entrar pensando no impacto sobre o resto do jogo.
