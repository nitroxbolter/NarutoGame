🛠️ Fase 5 - TFS 1.4.2 + OTCv8

Implementação Técnica

Arquitetura do servidor em TFS 1.4.2 com Lua, interface customizada via OTCv8 e estratégia de monetização saudável.

Stack Tecnológica

🖥️
TFS 1.4.2
Base do servidor OT. Scripts em Lua para sistemas de gameplay.
🎮
OTCv8
Cliente customizado com HUDs, widgets e painéis especializados.
🗃️
Banco de Dados
Personagens, progresso de rank, inventário e storages.

Checklist MVP Técnico

✅ O que deve estar pronto no primeiro lançamento
  • Sistema de atributos com fórmulas funcionais.
  • Progressão de rank até Jonin com NPC de promoção.
  • 5 elementos base com árvores de jutsu.
  • Spells com requisitos de storage e cooldown.
  • Missões D, C e B com progresso e entrega.
  • Economia funcional, lojas e loot tables.
  • Konoha completa com áreas funcionais.
  • 3 a 5 bosses com loot especial.
  • HUD básico de chakra e vida no OTCv8.
