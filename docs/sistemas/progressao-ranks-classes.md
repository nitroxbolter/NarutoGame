# Progressão, Ranks, Classes e Promoções

## Filosofia

A progressão não deve depender apenas de level. O personagem evolui por uma combinação de força, treino, mentalidade, reputação, missões, exames e conquistas.

## Ranks Ninja

| Rank | Função | Conteúdo liberado |
| --- | --- | --- |
| Estudante da Academia | Tutorial e introdução | Treino básico, missões simples, primeiros NPCs |
| Genin | Início real da carreira | Missões D e C, jutsus básicos, profissões |
| Chunin | Ninja intermediário | Missões B, dungeons iniciais, segundo elemento |
| Jonin | Elite da aldeia | Missões A, bosses fortes, técnicas avançadas |
| ANBU | Especialização avançada | Missões secretas, stealth, caçadas, conteúdo de elite |
| Sannin/Kage simbólico | Prestígio endgame | Conteúdo lendário, eventos globais, liderança |

## Classes ou Arquétipos

As classes podem funcionar como caminhos de especialização, não como prisões rígidas.

| Arquétipo | Foco | Exemplo de estilo |
| --- | --- | --- |
| Taijutsu | Treino, corpo a corpo, velocidade | Lutador agressivo |
| Ninjutsu | Mentalidade, chakra, elementos | Mago elemental |
| Bukijutsu | Armas ninja, precisão, críticos | Usuário de armas |
| Suporte Médico | Cura, purificação, proteção | Médico de grupo |
| Sensor | Detecção, controle, informação | Utilidade e estratégia |
| Assassino ANBU | Mobilidade, burst, furtividade | Caçador de alvos |
| Invocador | Contratos, criaturas, suporte | Controle por summons |

## Promoções

Cada promoção deve exigir uma mistura de requisitos.

| Promoção | Requisitos sugeridos |
| --- | --- |
| Academia para Genin | Tutorial completo, prova prática, jutsu básico aprendido |
| Genin para Chunin | Level mínimo, missões D/C, exame Chunin, boss de prova |
| Chunin para Jonin | Reputação, missão de liderança, dungeon concluída, domínio de jutsus |
| Jonin para ANBU | Quest secreta, teste de combate, reputação alta, recomendação de NPC |

## Exames

Tipos de prova possíveis:

- Prova teórica com perguntas de lore e mecânicas.
- Prova prática contra NPCs.
- Prova de sobrevivência em floresta.
- Prova em grupo.
- Prova de coleta ou escolta.
- Prova contra boss de instância.
