# Atributos

## Objetivo

Os atributos representam o crescimento do personagem e ajudam a diferenciar estilos de jogo.

## Base sugerida

- Vida.
- Chakra.
- Ninjutsu.
- Taijutsu.
- Genjutsu.
- Velocidade.
- Defesa.

## Direção de design

- Atributos precisam ter impacto visível.
- O sistema deve permitir builds diferentes sem quebrar o balanceamento.
- O crescimento deve ser simples de entender e fácil de comparar.
