# Missões

## Papel das Missões

Missões são a principal ponte entre narrativa, economia, exploração e progressão. Elas devem guiar o jogador sem tirar sua liberdade.

## Categorias

| Categoria | Exemplo |
| --- | --- |
| Academia | Aprender movimento, combate e jutsu básico |
| Rank D | Coleta, entrega, ajuda a NPCs |
| Rank C | Patrulha, caça simples, escolta curta |
| Rank B | Combate contra ninjas, dungeons pequenas |
| Rank A | Bosses, invasões, proteção de região |
| Rank S | Ameaças lendárias, bijuus, conteúdo de elite |
| Elemental | Aprender ou evoluir elementos |
| Profissão | Pescar, minerar, coletar, craftar |
| História | Arcos narrativos principais |
| Diária/Semanal | Retenção e rotina saudável |

## Missões da Aldeia

Missões da aldeia devem reforçar a sensação de pertencimento.

Exemplos:

- Ajudar a academia.
- Entregar suprimentos ao hospital.
- Patrulhar portões.
- Escoltar comerciantes.
- Capturar animais ou fugitivos.
- Coletar ervas para médicos.
- Investigar marcas de chakra.
- Defender a aldeia de ataque.

## Estrutura de uma Missão

Campos sugeridos:

- Nome.
- Rank.
- NPC inicial.
- Local.
- Objetivo.
- Requisitos.
- Etapas.
- Recompensas.
- Reputação.
- Continuação.

## Recompensas

- Ryo.
- Experiência.
- Reputação.
- Materiais.
- Pergaminhos.
- Itens.
- Acesso a NPCs.
- Progresso de promoção.
