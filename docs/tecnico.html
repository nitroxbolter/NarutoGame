🛠️ Fase 5 — TFS 1.4.2 + OTCv8

Implementação Técnica

Arquitetura do servidor em TFS 1.4.2 com Lua, interface customizada via OTCv8 e estratégia de monetização.

Stack Tecnológica

🖥️
TFS 1.4.2
The Forgotten Server. Engine base do servidor OT. Scripts em Lua para sistemas de gameplay.
🎮
OTCv8
Client customizado. Permite UI avançada com widgets, HUDs e painéis personalizados em Lua.
🗄️
MySQL / MariaDB
Banco de dados para personagens, storage IDs, progresso de rank e inventário.

Sistemas em Lua (TFS)

Cada sistema do jogo precisa de scripts Lua dedicados. Abaixo a estrutura de implementação priorizada para o MVP.

SistemaImplementaçãoPrioridade
AtributosStorage IDs para Treino e Mentalidade; fórmulas de dano/vida via onDeath e spell damageAlta
Rank NinjaStorage ID por rank; NPC de promoção com checagem de condições; unlock de áreas por rankAlta
ElementosStorage de afinidade elemental; árvore de jutsus filtrada por elemento; learn scriptAlta
JutsusSpells customizadas com requisito de storage; sistema de domínio via uso contínuoAlta
MissõesQuest scripts com contador de kills, coleta e NPC de entrega; reputação por storageAlta
EconomiaPreços de NPCs em XML; loot tables configuradas; sistema de recompensa de missãoMédia
BossesMonsters XML com scripts onDeath para loot especial e eventos globaisMédia
Domínio de JutsuContador de uso por storage; evolução automática ao atingir thresholdMédia

Interface OTCv8 (UI)

O cliente OTCv8 permite criar uma UI ninja completamente customizada, substituindo a interface padrão do OT.

💚
HUD de Vida e Chakra
Barras visuais customizadas no estilo ninja. Chakra separado da mana padrão do OT.
📋
Menu de Jutsus
Painel de técnicas organizadas por elemento, categoria e nível de domínio.
🥋
Janela de Rank
Exibe rank atual, progresso para o próximo e requisitos pendentes.
📜
Painel de Missões
Lista de missões ativas, objetivos e progresso em tempo real.
📊
Ficha de Atributos
Valores de Nível, Treino e Mentalidade com bônus calculados e distribuição visual.
🌿
Árvore de Elementos
Visualização da árvore de jutsus por elemento com status de desbloqueio.

MVP Técnico — Escopo Mínimo

O que deve estar funcionando no primeiro lançamento jogável.

✅ Checklist do MVP Técnico
  • Sistema de atributos (Nível + Treino + Mentalidade) com fórmulas funcionais
  • Progressão de rank até Jonin com NPC de promoção
  • 5 elementos base com árvores de jutsu independentes
  • Spells de jutsu com requisitos de storage e sistema de cooldown
  • Missões D, C e B com contador de progresso e entrega
  • Economia funcional: lojas, loot tables, recompensas de missão
  • Konoha completa com todas as áreas funcionais
  • 3 a 5 bosses com loot especial
  • HUD básico de chakra e vida no OTCv8
  • Sistema de domínio de jutsu (Aprendido → Mestre)

Monetização Saudável

A monetização deve manter o equilíbrio do servidor e nunca vender vantagens que quebrem a progressão orgânica.

👘
Cosméticos
Roupas, efeitos visuais, auras e aparências exclusivas. Nunca poder de combate.
📅
Daily Login
Recompensas progressivas por login diário. Retenção sem pay-to-win.
🎯
Passe de Temporada
Objetivos semanais com recompensas cosméticas e QoL. Nada que afete o PvP ou progressão.
⚡
Conveniência Limitada
Slots extras de missão ou XP boost com teto máximo. Nunca pula etapas de rank.
🚫 O que NUNCA vender
  • Jutsus exclusivos não obtíveis por progressão
  • Ranks ninja comprados diretamente
  • Itens com stats melhores que o endgame do servidor
  • Vantagens de PvP que não existem para jogadores gratuitos
