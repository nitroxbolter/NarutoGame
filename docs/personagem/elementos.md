# Elementos

## Função

Os elementos definem a afinidade principal do personagem e orientam quais árvores de jutsus ele consegue seguir.

## Elementos base

- Katon.
- Suiton.
- Raiton.
- Doton.
- Fuuton.

## O que o elemento afeta

- Primeira árvore de jutsus.
- Estilo visual das técnicas.
- Build inicial.
- Possíveis combinações futuras.

## Direção de progressão

- O primeiro elemento é o mais acessível.
- O segundo exige rank, missão e treinamento.
- O terceiro deve ser avançado e raro.
- Combinações especiais ficam para o endgame.

## Possibilidades futuras

- Kekkei Genkai.
- Técnicas exclusivas por linhagem.
- Mestres elementais.
- Pergaminhos raros e especializações secretas.
