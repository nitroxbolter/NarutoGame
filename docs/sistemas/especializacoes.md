# Especializações

## Objetivo

Especializações são caminhos que deixam o personagem mais único sem depender apenas de elemento ou rank.

## Exemplos de caminhos

- Ninjutsu.
- Taijutsu.
- Genjutsu.
- Fuinjutsu.
- Kenjutsu.
- Senjutsu.

## Direção de design

- A especialização deve reforçar o estilo de jogo.
- Cada caminho precisa de vantagens reais e custos de oportunidade.
- O sistema deve ser expansível para novos estilos depois do MVP.
